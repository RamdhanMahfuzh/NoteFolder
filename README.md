## About

NoteFolder is a mobile note-taking application developed using Flutter. It helps users create, organize, edit, delete, and search their personal notes with a simple and intuitive interface.

This project applies **BLoC** for state management and **Clean Architecture** to maintain a scalable, organized, and maintainable codebase.

##  Tech Stack

| Technology | Description |
|:---|:---|
| Flutter | Cross-platform mobile development |
| Dart | Programming language |
| BLoC | State management |
| Clean Architecture | Application architecture |
| sqflite | Local data storage |
| GetIt | Dependency injection |
| GoRouter | Navigation and routing |
| Dio | HTTP client and API integration |

##  Features

-  Create and manage personal notes
-  Edit existing notes
-  Delete notes
-  Search notes by title or content
-  Local data storage using sqflite
-  Network connectivity monitoring
-  Reactive UI updates with BLoC


##  Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/USERNAME/notefolder.git
```

**2. Navigate to the project directory**

```bash
cd notefolder
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
